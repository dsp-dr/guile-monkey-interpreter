* Purpose

A GNU Guile Scheme implementation of the Monkey programming language interpreter
from Thorsten Ball's /Writing An Interpreter in Go/, extended with additional
language features and built-in functions beyond the book.

* Goals

- Faithfully implement all four chapters of the book (lexer, parser, evaluator, extensions)
- Adapt Go idioms to idiomatic Scheme (SRFI-9 records, pattern matching, closures)
- Extend Monkey with practical features (for loops, break/continue, higher-order builtins)
- Provide chapter-by-chapter snapshots so readers can follow along incrementally

* Non-Goals

- Production-grade interpreter (no sandboxing, no security boundaries)
- Bytecode compilation or VM (this is a tree-walking interpreter only)
- Compatibility with other Monkey implementations

* Key Design Decisions

- *Pratt parsing* for operator precedence, matching the book's approach
- *SRFI-9 records* for all AST nodes and runtime objects (not plain lists)
- *SRFI-69 hash tables* for parser dispatch (prefix/infix fn registries)
- *call/cc* used for early return in parser via =with-return= macro
- *Built-in functions* registered in a single match dispatch in the evaluator
- *Immutable data model*: push/rest/delete return new objects, never mutate

* Language Features Implemented

** Core (Chapters 1-4)

- Integer, boolean, string, array, hash literals
- Let bindings, return statements, expression statements
- Prefix operators: =!=, =-=
- Infix operators: =+=, =-=, =*=, =/=, =<=, =>=, ===== , =!==
- If/else expressions
- First-class functions and closures
- Index expressions for arrays and hashes
- 6 core built-ins: len, first, last, rest, push, puts

** Extensions Beyond the Book

- While loops: =while (cond) { body }=
- For loops: =for (init; cond; update) { body }=
- Break and continue statements
- Lambda shorthand: =|x| x + 1=
- 9 Chapter-4 built-ins: type, str, int, split, join, contains, keys, values, delete
- 11 quick-win built-ins: map, filter, reduce, sort, abs, min, max, trim, replace, substring, format

* Current Status

- Chapters 1-4: complete
- All core Monkey features: working
- For loops, break/continue: implemented and tested
- Lambda shorthand: parser support implemented
- IR layer (=src/monkey/ir/=): experimental, not integrated into main evaluator

* Known Limitations

- No tail call optimization (deep recursion will overflow the stack)
- No module/import system
- No pattern matching in the Monkey language itself
- The =format()= built-in uses indexed placeholders (={0}=, ={1}=), not full interpolation syntax
- =code/04/= contains only a README; Chapter 4 features live in =src/= directly
- Static test badge in README (not CI-driven)
- No sandboxing: the interpreter trusts all input
